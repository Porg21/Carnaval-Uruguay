# Carnaval Uruguay · v0.3 (pruebas)

[Probar el juego en GitHub Pages](https://porg21.github.io/Carnaval-Uruguay/)

Versión de prueba con cuentas Supabase, partidas nuevas, cinco formaciones titulares fijas, suplentes, finanzas semanales, club ampliable, cantina, merchandising y utileros. Incluye el prototipo jugable de la Prueba de Admisión con sorteo de octubre, jornadas de noviembre, resultados alfabéticos y opción de continuar o pausar tras la eliminación.

Las cuentas de v0.2 se conservan. Las partidas antiguas no se cargan en v0.3 y se sobrescriben al crear una partida nueva.

**Alcance:** la simulación competitiva completa del Concurso Oficial de febrero (jurados, rondas, Liguilla y Fallos), tablados con calendario real y ciertos sistemas avanzados quedan para futuras versiones. Febrero y marzo son actualmente etapas de transición que permiten completar el ciclo anual y seguir desarrollando el conjunto.

Código estático en GitHub Pages, guardado por cuenta en Supabase. No incluir claves secretas de servidor en el frontend.
